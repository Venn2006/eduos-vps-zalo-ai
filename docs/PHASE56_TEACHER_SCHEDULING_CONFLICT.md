# Phase 56 — Teacher/Học vụ Workspace + Scheduling Conflict Detection

## 1. Context
EduOS is positioned as a Base SaaS for Vietnamese language centers. While previous phases focused on Sales/CRM and Lead follow-up (Phases 54 & 55), Phase 56 shifts focus to **Academic Operations (Học vụ & Giảng dạy)**. It provides a robust, sandbox-safe workspace for teachers and coordinators to manage classes, attendance, homework, and scheduling conflicts.

## 2. Goal
Help the Center Owner or Academic Coordinator instantly answer:
- Hôm nay có lớp nào?
- Giáo viên nào bị trùng lịch?
- Phòng nào quá tải?
- Lớp nào chưa điểm danh?
- Việc nào cần giáo viên duyệt?

## 3. User Value
- **Giáo viên**: Dễ dàng xem lịch dạy, điểm danh nhanh, xem bài tập chờ chấm.
- **Học vụ**: Tự động phát hiện trùng lịch giáo viên/phòng học (Scheduling Conflict) mà không cần dò thủ công.
- **Owner**: An tâm vì mọi thao tác của AI (chấm điểm, báo cáo phụ huynh) đều yêu cầu `TEACHER_APPROVAL_REQUIRED`.

## 5. Academic Demo Data Model
- `MockAcademicSession`: Contains deterministic scheduling info (teacher, room, time) and status flags (attendance, homework, report).
- Mock data explicitly creates conflicts (e.g. Teacher `t1` assigned to two overlapping sessions at 18:00 and 18:30, Room `r2` booked twice at 18:30).

## 6. Scheduling Conflict Detection Rules
- **TEACHER_CONFLICT**: Same teacher assigned to overlapping sessions.
- **ROOM_CONFLICT**: Same room booked for overlapping sessions.
- **CAPACITY_WARNING**: Student count exceeds room capacity limit.
Severity levels: `Chặn demo`, `Cần xử lý`, `Cảnh báo`.

## 7. Attendance Workflow
Shows missing attendance explicitly. Actions are prefixed with "Demo" (e.g. `Điểm danh demo`) to ensure safe Sandbox execution.

## 8. Homework/Parent Report Approval Workflow
Homework and Parent reports generated by AI are flagged as `Cần giáo viên duyệt` with strict `TEACHER_APPROVAL_REQUIRED` mode, enforcing humans-in-the-loop.

## 9. Teacher Task Center
Academic tasks automatically appear for the teacher (e.g. "Duyệt nhận xét AI", "Báo học vụ đổi phòng"). Task statuses clearly indicate if action is overdue.

## 10. Approval/Safety Matrix
- **NO DB PUSH / NO MIGRATIONS**.
- All data is entirely mocked and local.
- No real APIs, Zalo sends, or Live LLMs are used.

## 11. Demo Storyline
1. Owner opens "Workspaces -> Teacher/Học vụ".
2. Sees a critical alert: "Trùng lịch" (1).
3. Opens the "Trùng lịch" tab, discovers Nguyễn Văn A is scheduled for both IELTS and Giao tiếp classes simultaneously.
4. Moves to "Giáo viên cần duyệt", sees an AI-drafted parent report waiting for teacher approval.
